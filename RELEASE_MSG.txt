RepoScope 0.8.1 — the window looks like the app

Fixes the two things that were wrong with the first desktop build.

## Fixed

Settings could not be reached before the first scan. The button lived only in the map
header, so a freshly installed app had nowhere to enter a licence key or change how updates
behave until you had scanned something first — backwards, since activating is the first
thing you do after installing. It is now in the landing header too, and the smoke test
opens it from a cold start and checks the licence box is there.

## Changed

The window wears the app's own header instead of native chrome. The
File/Edit/View/Window/Help menu bar is gone on Windows and Linux: noise above a
single-window app with nothing to put in it, sitting on top of the app's own header. macOS
keeps a minimal menu because there it is not optional — the clipboard shortcuts are wired
through the Edit menu and stop working in text fields without it.

On Windows and macOS the native title bar is hidden and the header acts as one: drag it to
move the window, with the real minimise/maximise/close buttons overlaid on Windows and the
traffic lights inset on macOS. Linux keeps its native decorations, because hiding the title
bar there removes the window controls entirely rather than overlaying them.

## Updating

If you are on 0.8.0 with updates set to "ask me" or "install automatically", this arrives on
its own — the download is checked against the SHA-256 published below before it is kept.
Otherwise the installers are attached to this release, with a .sha256 beside each.
